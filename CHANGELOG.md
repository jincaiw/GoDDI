# Changelog

## v0.25.1 — 2026-11-20

- Clear the CI gate debt that surfaced after v0.25.0. The branch had accumulated 51 un-pushed commits that never ran CI; this release makes all five CI jobs pass.
- lint: fix 33 golangci-lint findings (ineffassign 5, staticcheck 21, unused 7). Deliberate nil-context negative tests are annotated with a justified nolint rather than changed.
- security (Go): bump the toolchain to 1.26.11 (standard-library fixes in 1.26.9-1.26.11) and golang.org/x/net to v0.60.0; govulncheck is now clean.
- security (frontend): upgrade axios, vite, vue-i18n, qs and oxfmt, and pin transitive packages (follow-redirects, source-map-js, tinypool, @vue/server-renderer, @intlify/*, braces, decode-uri-component, esbuild, glob, micromatch, minimatch, postcss) via pnpm overrides. pnpm audit reports no known vulnerabilities and the frontend still builds.
- Note: the v0.25.0 tag was published with red CI; its binaries were fine, but this release supersedes it as the first green-CI release of the TDesign console.

## v0.25.0 — 2026-11-20

- Rebuild the admin console on the TDesign Vue Next Starter theme, replacing the
  Naive UI frontend. All 30 business routes, the API surface and the DNS, DHCP
  and IPAM flows remain usable.
- Align the console with the upstream starter layout: 56px header, 64px
  collapsed sider, #0052D9 brand, 6px radius and an 11-section settings drawer,
  with light and dark themes driven from one token source.
- Fix dialog sizing so modals stay inside the viewport at every screen size; the
  previous fix only covered mobile and left the confirm button off-screen on
  desktop.
- Make delete confirmations render a readable subject instead of an empty body
  and an opaque UUID.
- Resolve zone-type and revision-note enums through the locale tables instead of
  printing raw backend tokens.
- Validate zone names as domains before they reach the API.
- Render the configured watermark (it was never displayed) behind a drawer switch.
- Remove four frontend modules with no importer (useEcharts, useCaptcha, the
  unused REG_* constants and isPC).
- Stop tracking web/dist (regenerated by `make web-build` and the Dockerfile)
  and fix the image build: exclude web-admin/node_modules, allow overriding
  GOPROXY and cache Go modules, so a workstation build no longer hangs.
- Keep the existing production and deployment boundaries unchanged.
