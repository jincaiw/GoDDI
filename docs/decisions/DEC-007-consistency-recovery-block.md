# DEC-007：不一致时的阻断与恢复（正式条目）

- 状态：**已确认（2026-11-12，随 ADR-0010 批准）**
- 权威来源：`docs/adr/0010-replication-loss-service-policy.md`、`docs/adr/0003`
- 关联：DEC-006

## 决策
必须区分两类故障、两套状态机：
1. **链路中断（link loss）** → `paused`；不承诺新/延长租约；可由运维显式 `ha degrade` 在本地持久化后继续（见 DEC-006）。**不得自动解除暂停**。
2. **检出不一致（inconsistency：日志缺口/乱序、哈希链断裂/分叉、Lease/Facts 水位矛盾、身份/所有权冲突）** → **`blocked` 阻断状态**；**禁止**用普通重试/超时/自动对账解除；必须人工按证据清理并重新验证后才可恢复镜像。

只有"日志链完整、身份/所有权正确、Lease/Facts 一致、无冲突且双端持久化屏障验证成功"才可自动恢复正常镜像状态。

## 验收
- 注入缺口/分叉/哈希不符 → 进入 `blocked` 且不自动恢复；
- `blocked` 需人工证据 + 审批清理；
- 与 DEC-006 的 `paused`（链路中断）严格区分，不混用状态机。
