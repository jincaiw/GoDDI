## 五、本轮已修复问题（31 个文件）

| # | 问题 | 修复 |
| --- | --- | --- |
| 1 | Go 1.26.2 存在 5 个 stdlib 漏洞（x509/asn1、net/http 路径） | `go.mod`、`ci.yml`、`release.yml` 升级至 **Go 1.26.6**，扫描归零 |
| 2 | **信息泄露**：89 处接口把 `err.Error()` 直接返回客户端 | 新增 `response.InternalErrorWithLog`，服务端 `slog.Error` 记录、客户端只回通用文案（19 个 handler 文件全量替换） |
| 3 | 指标桶无界增长（客户端/域名/rcode 等 map 无上限） | `topstats.go` 增加 `bumpCapped`，每类上限 100，溢出聚合到 `(other)` |
| 4 | NOTIFY 触发的区域刷新无并发控制，可被放大 | `server.go` 新增 `scheduleNotifyRefresh`：最多 2 并发 + 同区 10s 抑制 |
| 5 | **SSRF**：拦截列表可指向内网地址 | `fetcher.go` 禁用重定向 + 拨号前拒绝回环/私网/链路本地/未指定地址；`dns_security.go` 创建与更新阶段同步校验（此前仅 `external` 类型校验且只检查 scheme） |
| 6 | **区域名/记录名零校验**：`..`、`a..b`、`-bad.test`、`含中文.test`、300 字符名称均被接受 | 新增 `dnsutil.ValidateZoneName` / `ValidateRecordName`（支持 `@`、`*` 通配符、相对名），接入区域与记录的新增/更新，并补充单元测试 |
| 7 | **备份 ID 不存在返回 500** | 新增 `backup.ErrNotFound` 哨兵；Get/Download/Restore/Delete 统一映射 404，且不再回显错误原文 |
| 8 | `/metrics` 免认证暴露请求量与路由分布 | 已加认证中间件（本轮验证为 401） |

## 八、遗留风险（未解决，需知悉）

### P1

1. **DNSSEC 未真正签名**：`SignZone` 仅置标志位，不生成 RRSIG。开启后会产生"已签名"的假象，校验方可能判为失败。
2. **SQLite `SetMaxOpenConns(1)`**：备份/恢复等长事务期间 API 整体阻塞。本轮已修掉一处由此引发的死锁，但根因仍在。
3. **登录锁定 15 分钟且落库、无解锁入口**：攻击者可针对管理员账号实施拒绝服务，运维侧仅能直接改库恢复。

### P2

4. 默认明文 HTTP，未提供 TLS 终止指引；CSRF 令牌未与会话绑定。
5. `/api/v1/openapi.json` 免认证，暴露完整接口清单。
6. 转发器上游未过滤私网地址；`client.go` 调试查询的 SSRF 校验仅覆盖 IP 字面量。
7. 缓存 `Get` 持独占锁且无后台清理；`PopularEntries` 为 O(n²)。
8. DHCP 服务无 panic 恢复、请求队列无界。
9. 上游转发路径每次查询新建 `dns.Client`/套接字，高并发下 fd 与端口压力偏大。
10. 单元测试覆盖率 13.3%，DNS 核心与 DHCP 近乎无覆盖。
11. `golangci-lint` 未纳入 CI，静态检查强度有限。
