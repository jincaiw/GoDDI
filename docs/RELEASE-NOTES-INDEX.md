# 发布说明索引（Release Notes Index）

GoDDI 的发布历史目前存在于两处，本文说明权威来源与缺口，避免误引。

## 权威来源

- **`CHANGELOG.md`（仓库根）**：**v0.24.0 起的唯一权威记录**（v0.24.0 / v0.24.1 /
  v0.25.0 / v0.25.1 及后续）。
- **`docs/release-notes-<tag>.md`**：早期版本的补充记录，覆盖
  v0.1.0–v0.1.3 与 v0.11.0–v0.22.0；**保留作为历史记录，不再新增**。

## 已知缺口（无独立 release-notes 文件的 tag）

v0.1.4–v0.1.12、v0.2.0–v0.10.0（含 v0.3.1/v0.5.1/v0.5.2/v0.8.x）、
v0.23.0、v0.24.0、v0.24.1、v0.25.0、v0.25.1。

- v0.24.0 起的缺口由 `CHANGELOG.md` 覆盖。
- v0.1.4–v0.23.0 之间无独立发布说明，历史信息见 git tag 与相关提交记录。

## 约定

- 新版本发布：只更新 `CHANGELOG.md`，不再新增 `docs/release-notes-*.md`。
- 如需追溯旧版本，以对应 `git tag` 为准。
