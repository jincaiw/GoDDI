## 三、FAIL（未通过 / 阻塞发布）

### FAIL-1：发布产物 `web/dist` 已过期，缺少本次新增前端功能
- 现象：Go 二进制在编译时内嵌 `web/dist`（`assets.go` 的 `//go:embed all:web/dist`）。仓库中 `web/dist`（64 个受版本控制文件）的构建时间早于本次全部前端改动，其中**不包含**本次新增的「允许区域 / 阻断区域 / 应用」页面，也不含 Catalog 挂靠选择器与 DNSSEC 增强 UI（已用字符串检索确认）。
- 影响：若直接发布，用户拿到的是旧界面，本次 Web UI 改动全部不可见。
- 修复方式（需在有完整 Node 工具链的环境执行）：
  ```bash
  cd web-admin && pnpm install --frozen-lockfile && pnpm build && cd ..
  go build ./cmd/goddi   # 重新编译以嵌入新 dist
  ```
- 本次未能自动修复的原因：当前沙箱环境 pnpm 创建符号链接被拦截（`ERR_PNPM_CODEBUDDY_BROKER_DENY` / `EEXIST`），npm 不支持仓库使用的 `workspace:` 协议，因此前端依赖与构建无法在本环境完成。
