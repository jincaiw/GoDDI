## 二、修复的问题清单（共 24 项，3 次提交）

### 提交 1（0619f3b）：关键正确性与安全修复

| # | 级别 | 问题 | 修复 |
|---|---|---|---|
| 1 | **P0** | 租约过期判定失效：`lease_end` 以 RFC3339（含 `T`）写入，`ExpireLeases`/`DeleteScope` 用 `datetime('now')`（空格分隔）做字符串比较，`'T'>' '`导致**当天到期租约永不回收**，地址池会被耗尽（`internal/dhcp/lease/lease.go:309`、`scope.go:357`） | 比较改为 `julianday()`，兼容两种格式；新增 `lease_test.go` 回归测试 |

## 三、确认无需修复 / 遗留事项

| 项 | 结论 |
|---|---|
| SQLite PRAGMA per-connection 失效风险 | 池被 `SetMaxOpenConns(1)` 限制为单连接，PRAGMA 实际稳定生效，无需 DSN 化 |
| `/metrics` 无鉴权 | Prometheus 抓取惯例，建议生产环境用网络层隔离（已记录） |
| `EnableDNSSEC` 只置位无真实签名 | 大型功能缺口，需要独立的 DNSSEC 签名引擎，建议列入下一版本规划 |
| TOTP 重放窗口、audit 1MiB 截断、备份同步执行、错误信息大面积外泄（约 100 处 `err.Error()` 拼响应） | 健壮性优化项，未在本次范围内全部处理，建议后续专项 |
| cluster/apps 接口 | 501 占位（设计如此） |
| Playwright e2e | 3 个 spec 存在（api/console/workflows），依赖系统 Chrome 与专用端口环境，本次以 API 集成测试 + 协议实测替代覆盖 |
